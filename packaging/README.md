# Distribution Packaging Configs

This directory contains release packaging definitions for third-party installers:

- Homebrew tap formula
- Scoop manifest
- Winget manifests
- Snap config
- AUR PKGBUILD
- Nix package definitions

## Rendering release-ready manifests

Most package managers require exact release URLs and SHA-256 digests.
Use:

```bash
scripts/release/render-distribution-configs.sh \
  --version vX.Y.Z \
  --checksums-dir release-assets \
  --output-dir release-assets/distribution
```

The command reads `CHECKSUMS-*.sha256` generated by `oss-release.yml` and renders
fully resolved manifests into `release-assets/distribution/`.

The source manifests in this directory intentionally contain `@...@` tokens for
release version and checksum interpolation.
